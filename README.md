🏫 CampusCare – College Complaint Management System

📌 Project Overview

CampusCare is a web-based College Complaint Management System designed to make it easier for students to report campus-related issues and track their complaints efficiently.

The platform provides a simple and user-friendly interface where students can submit complaints, upload photos as evidence, and receive notifications about complaint updates. Administrators can manage complaints, monitor their status, and take appropriate action.

The main goal of CampusCare is to improve communication between students and college administration while ensuring a transparent and organized complaint management process.

✨ Features

- Student Login: Secure login interface for students.
- Complaint Submission: Students can submit complaints related to campus facilities and services.
- Photo Upload: Attach photos as evidence while submitting complaints.
- Complaint Tracking: Track complaint status and progress.
- Notification System: Receive notifications about complaint updates.
- Admin Dashboard: Administrators can view and manage submitted complaints.
- QR Code Scanner: Supports QR code scanning functionality.
- Status Management: Update complaints as Pending, In Progress, or Resolved.
- User-Friendly Interface: Simple and responsive design.

🛠️ Technologies Used

- HTML5 – Structure
- CSS3 – Styling and layout
- JavaScript – Functionality and interactivity
- LocalStorage – Storing complaint and notification data
- HTML5 QR Code Library – QR code scanning
